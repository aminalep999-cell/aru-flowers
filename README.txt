# Aru Flowers — PWA

Это PWA-версия сайта Aru Flowers.

## Как установить на Android через Chrome
1. Разместите папку на HTTPS-сайте (или тестируйте через localhost).
2. Откройте сайт в Chrome на Android.
3. Нажмите «Установить» на сайте, если кнопка появилась, либо меню Chrome → «Установить приложение».
4. После установки Aru Flowers появится как отдельная иконка на смартфоне.

Важно: обычное открытие `index.html` двойным кликом не даёт полноценную PWA-установку. Для Service Worker нужен HTTPS или localhost.
